# LaTeX Student Resume Template
A clean and ATS-freindl LaTeX resume template for students and early-career professionals in technical fields.  

This template is based on [Jake’s Resume](https://www.overleaf.com/latex/templates/jakes-resume/syzfjbzwjncs) and includes several improvments:
- Fixed font and encoding issues
- Cleaner and more readable LaTeX code
- Improved indentation and spacing
- Extensive in-line documentation

---

## Getting Started

### Option 1: Use Overleaf (Recommended)

1. Go to [Overleaf](https://www.overleaf.com/).
2. Upload the `main.tex` file directly, or
3. If you have Overleaf Premium, you can import this repository using Git.  
   Follow this [Overleaf GitHub Integration Guide](https://docs.overleaf.com/integrations-and-add-ons/git-integration-and-github-synchronization/github).
4. Replace placeholders and click **Recompile** to generate your PDF.

### Option 2: Compile Locally

1. **Clone the repository**:
   ```bash
   git clone https://github.com/f-abdinov/student-resume-template.git
   cd latex-resume-template
   ```
   
2. **Replace placeholders** with your information in `main.tex`

3. **Compile locally**:
   ```bash
   pdflatex main.tex
   ```
